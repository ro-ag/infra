# Rust CI/CD audit — 2026-08

Audit of GitHub Actions across all Rust repos in `~/dev/rs`. Runner minute
cost: **Linux 1x, Windows 2x, macOS 10x**.

## Fleet-wide patterns (the real problems)

1. **Merge → release duplication.** The single biggest waste. On the typical
   path a commit passes CI on `main`, gets tagged, and the release pipeline
   then re-runs the same tests and/or re-builds the same artifacts from
   scratch:
   - `pam`: main CI builds + verifies + signs + notarizes all 5 platform
     packages, then `release.yml` rebuilds and re-notarizes everything. CI
     artifacts are never reused. ~400 lines of near-verbatim duplication
     between the two files.
   - `ptrack`: `release.yml` test job is a byte-for-byte repeat of the
     acceptance suite on the same commit; frontend rebuilt ~7x per release.
   - `native-ipc-rs`: release gate polls until CI is green on the commit —
     then re-runs the entire quality gate anyway. Pick one.
   - `hexy`: `validate` job re-runs the full CI suite on the tagged commit.
   - `metro-2`: `main-merged.yml` is a line-for-line copy of the PR suite,
     so every PR runs everything twice.
2. **Caching absent or misused.**
   - No cache at all: `metro-2`, `native-rack`.
   - Registry-only cache (`~/.cargo/registry`), `target/` not cached — the
     expensive part recompiles every run: `native-score`, `parser` (both with
     heavy dep trees: eframe/wgpu, arrow/parquet).
   - Release/publish jobs cold even where CI caches: `brano` (release job
     `rm -rf`s the cargo registry + sysroot for disk space),
     `croma/publish.yml`, `native-ipc-rs/release.yml`, `verovio-rs/publish.yml`.
   - `croma/audit.yml` compiles `cargo-audit` from source every run.
3. **CI triggers broken or missing.** `brano` CI fully disabled (commented
   triggers; releases ship untested code). `native-rack` and `native-score`
   are `workflow_dispatch`-only — nothing runs on PR or merge.
4. **No `concurrency` cancellation** on PR workflows: `brano`, `croma`,
   `native-ipc-rs`, `parser`. Stale runs burn full matrices.
5. **Redundant compiles within one job**: `check` + `clippy --all-targets` +
   `test` triple-compile the same graph (`croma`, `pam`, `parser`).
   Clippy already type-checks all targets; drop the separate `check`.
6. **Toolchain drift**: no `rust-toolchain.toml` in `hexy`, `metro-2`,
   `parser`, `verovio-rs`, `ptrack`; `brano` CI uses `@stable` while the
   repo pins 1.97.0. fmt/clippy results shift under the repo's feet.
7. **Expensive runners ungated**: `metro-2` runs macOS on every PR push for a
   pure-Rust library; `native-ipc-rs` runs a 5-OS matrix + ASan + Miri + fuzz
   on every PR push; `pam` notarizes macOS on every merge for 7-day-preview
   artifacts nobody ships.

## Quick wins per repo

- **brano**: re-enable CI triggers; add rust-cache to release (restore-only
  before the disk cleanup); pin CI to 1.97.0.
- **croma**: add rust-cache to `publish.yml`; cache the cargo-audit binary;
  drop the redundant `cargo build --all-targets` after clippy; add
  concurrency to `ci.yml`.
- **hexy**: add `rust-toolchain.toml`; drop `validate`'s duplicate suite
  (check the commit's CI status instead); add `workflow_dispatch` to release.
- **metro-2**: delete `main-merged.yml` (fold `push: [main]` into one
  workflow); add rust-cache; move macOS to main-only; add MSRV 1.75 job;
  build the tag-release workflow its AGENTS.md mandates.
- **native-ipc-rs**: release gate: keep the CI-status poll, delete the local
  re-run (or vice versa); add concurrency + path filters to CI; move
  ASan/Miri/fuzz to nightly.
- **native-rack**: add PR/main triggers and rust-cache; split lint to a
  Linux-only job gating the matrix.
- **native-score**: add PR/main triggers; switch to `Swatinem/rust-cache`
  (target/ is the cost); add a CI-green check to release.
- **pam**: release downloads the main-run artifacts instead of rebuilding
  (see guide §6, pattern B); gate macOS notarization to tags; drop the
  `labeled` PR trigger re-running everything on any label.
- **parser**: switch to rust-cache; drop the separate `cargo clippy` compile
  or merge into one command; add concurrency; reconsider `--jobs 1`.
- **ptrack**: release: trust the main-run checks, skip the test job; build
  the frontend once and pass `dist/` to the matrix via artifacts.
- **verovio-rs**: add ccache to publish; poll the crates.io sparse index
  instead of `sleep 30`; collapse the 7 copy-pasted CI jobs into a matrix.
